# Exam Method

The idea comes from HTES Phase 1; the method below is HCES's own.


- Three volumes: A, B, C. Tune on A+B, test on C; tune on A+C, test on B; tune on B+C, test on A. Pool the three test results.
- Cutoffs are frozen before the confirmation set is built.
- Report run-to-run noise from one repeated volume; a difference smaller than the noise is not a difference.
- Count answerability two ways: unanswerable questions marked "not in the documents" (good), and answerable questions marked that way (a miss).
- A failed bar is reported as failed with its number, never softened.
- Second rubric: real use writes a fresh rubric per prompt, so measure that too. If kept sets differ by more than run-to-run noise, rubric wording is a bigger risk than JEV.
